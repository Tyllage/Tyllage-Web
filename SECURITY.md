# Security Policy

This repository is maintained privately by **Tyllage LLP**. It is not an open-source project.

## Reporting a vulnerability

If you believe you have found a security vulnerability in the Tyllage website or its infrastructure,
please report it **privately**:

- **Email:** [tyllage.co@gmail.com](mailto:tyllage.co@gmail.com) with the subject line
  `Security report: Tyllage-Web`
- Include a description of the issue, the affected URL or file, steps to reproduce, and its likely
  impact.

**Do not** open a public GitHub issue, pull request or discussion about a vulnerability, and do not
disclose it publicly until Tyllage LLP has confirmed it is resolved.

## What to expect

- We aim to acknowledge reports within **5 business days**.
- We will let you know whether we accept the report and, where appropriate, when it is fixed.
- Tyllage LLP does not currently run a paid bug bounty programme.

## Scope

In scope: the website served at Tyllage domains and the code in this repository.

Out of scope: denial-of-service testing, social engineering, physical attacks, spam, and findings in
third-party services that Tyllage does not control.

## Good-faith research

Please act in good faith: only test against what is in scope, do not access, modify or delete data
that is not yours, and stop and report as soon as you find an issue. Reporting a vulnerability does
not grant any licence to the code or content of this repository; see [LICENSE](LICENSE).
